Joy-Con Diagnostics

A technical tool of Clay Rush to check the real Joy-Con 2 in about two minutes. Nobody on the team has been able to try the real controller: everything that depends on the hardware stays UNVERIFIED-ON-HARDWARE until you confirm it in the checklist at the bottom of the page.

Mode: Native bridge (recommended) Open the game

Connection UNVERIFIED-ON-HARDWARE

Press “Connect”, hold down the Joy-Con's SYNC button until the lights sweep, then choose the controller in Chrome's list. Never pair it from the macOS Bluetooth settings. One attempt per click.

The game must have been started with start.command from Terminal (the first time, macOS asks for Bluetooth permission for Terminal). Press “Connect” and right after that hold down the Joy-Con's SYNC button, the small button next to the USB-C port, until the lights sweep: there is no list to choose from. Never pair it from the macOS Bluetooth settings. One attempt per click. Works with any browser.

The Joy-Con talks to only one page at a time: before opening the game press “Disconnect” (the link below does it for you), and the game in turn lets go of the controller when you open this page.

Stick check (about 30 seconds): leave it alone and watch the centre estimate settle, push it up, down, left and right and watch the sign of the normalised values (up must read +y, right +x) and one flick per push, then press A and B and watch the pressed buttons. The half range is an assumption: push it as far as it goes and report the largest raw values you see.

Scale used by the parser: accelerometer raw / 4096 = g; gyroscope raw x 2000/32768 °/s (scale disputed, see the “full revolution” tool).

Keep-alive experiment (60 s) UNVERIFIED-ON-HARDWARE

Connect the Joy-Con with keep-alive OFF and do not touch anything for 60 s. If macOS drops the link after about 15 s without messages from the computer (UOH-5), you will see it here. Press “Start”: the page disconnects, turns keep-alive off and reconnects (hold SYNC when prompted). When it is done, turn keep-alive back on with the checkbox above.

Full revolution (gyroscope scale) UNVERIFIED-ON-HARDWARE

Lay the Joy-Con flat on the table, press “Start”, hold it still for 1 s, then rotate it through ONE full revolution at a moderate speed and press “Stop”. About 360° confirms the default scale; about 2930° means 0.0075 °/s per unit (8.14 times smaller).

Gyroscope sign (gravity vs gyroscope) UNVERIFIED-ON-HARDWARE

Hold the Joy-Con still for 2 s, slowly rotate it by about 70-90° around a horizontal axis (for example tip up) and hold it still again. The test compares the rotation indicated by gravity with the one from the gyroscope.

Rest check (3 s) UNVERIFIED-ON-HARDWARE

Lay the Joy-Con flat on the table with the buttons up and do not touch it: |a| must be 1.00 ± 0.03 g, the gyroscope about 0 ± 3 °/s and the raw Z axis about +4096 (+1 g). The same Z decides the accelerometer sign (see below).

Accelerometer sign UNVERIFIED-ON-HARDWARE

The game assumes that at rest the accelerometer reads +1 g pointing UP. If Z reads -4096 with the buttons up, the sign is opposite: save “-1” and the game will apply it by itself (or open the game with ?accelsign=-1). The gyroscope test cannot notice this.

The gyroscope scale and sign you save apply to every later start of the game with the Joy-Con, until you clear them here.

Latency probe UNVERIFIED-ON-HARDWARE

Expert UNVERIFIED-ON-HARDWARE

Vibration (UOH-13): command 0x0A with presets 1, 3, 5, 6. Uses only the command characteristic. Never writes anywhere else.
