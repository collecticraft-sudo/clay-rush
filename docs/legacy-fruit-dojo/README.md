# Documents of the game Clay Rush was forked from

Clay Rush started as a fork of [3D Fruit Dojo](https://github.com/collecticraft-sudo/3d-fruit-dojo), a fruit-slicing game for the same
controller. Its documents (game design, architecture, motion findings, review and QA reports) live in that repository.

Only `protocol-audit.md` is kept here: it is the independent audit of the Joy-Con 2 Bluetooth protocol that the reused input code still
follows, and the hardware checklist in [`docs/GUIDE.md`](../GUIDE.md) refers to its findings.
